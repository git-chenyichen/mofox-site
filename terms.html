服務條款 (Terms of Service)

當您使用本機器人功能時，即代表您同意以下規範：

1. 使用規範

  • 禁止利用 MoFox Bot 進行任何形式的騷擾、詐騙或違反 Discord 官方社群守則之行為。
  • 嚴禁嘗試攻擊機器人後端 API 或惡意洗指令以造成服務負擔。
  • 若發現功能異常，請至官方支援伺服器回報。嚴禁利用程式漏洞（Bug）獲取非正常的伺服器權限或經濟數值。

2. 權限與責任

  • 伺服器管理員需自行承擔賦予機器人權限之風險（如「管理員」權限）。
  • 對於因 Discord 官方 API 故障或不可抗力因素導致的服務中斷，開發團隊不負賠償責任。

3. 贊助與虛擬物品

若涉及贊助或伺服器內部的虛擬代幣交易，請注意：這些物品僅具備社群內部紀念或功能性質，不具備任何現實貨幣價值。一旦完成贊助，原則上不接受退款要求。

隱私權政策 (Privacy Policy)

MoFox Bot 致力於保護使用者的資料安全，以下說明我們的資料處理方式：

1. 資料收集範圍

  • 必要識別資訊： 包含您的 Discord User ID、伺服器 ID。這些資料用於區分不同用戶的設定。
  • 功能執行紀錄： 為了實現「E-mail審核」或「購買物品」功能，我們會暫存相關頻道的 ID 與設定內容。

2. 數據處理與安全

  • 我們承諾不會將任何伺服器成員名單、對話內容或個人識別資料出售給第三方。
  • 數據儲存於加密資料庫，僅限開發團隊（MoFox Team）因維護需求進行必要存取。

3. 您的權利

若您希望完全刪除資料庫中關於您的所有紀錄（如經濟系統、設定），請聯繫開發團隊，我們將在核實身分後手動執行刪除程序。
